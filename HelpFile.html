Orchid Management System — System Architecture & Technical Manual (v6.0)

📂 Detailed System Module Index

1. System Security, Vault & Global Configuration Security Layer

Decouples private environment variables (Spreadsheet GUIDs, Drive Folder IDs) from script logic to allow safe public and repository sharing.

  • Config.gs / Globals.gs: Exposes the global CONFIG object wrapper. Securely fetches MAIN_SS_ID and GOVEE_FOLDER_ID via PropertiesService.getScriptProperties().
  • Sanitizer.gs: Executes runSystemSanitization() to extract the active spreadsheet key and write it to private properties during initial setup.
Archival Standard: Transitioned project branding to The Satyrion Chronicles across all core manifest references.

2. Care Logging, Maintenance & Historical Sync Care Pipeline

Enforces structured data collection for daily maintenance while providing bulk entry and historical backfill mechanisms.

  • WateringLogic.gs & WateringDialog.html: Modeless interactive modal dialog. Accepts comma-separated non-adjacent row inputs (e.g., 38, 47, 51) and restricts care methods to standard options (Soak, Mist, Flush, Pour, Spot Watering).
  • Row 56+ Ledger Transcription: Bulk watering automatically writes to Columns C, D, and E on the Maintenance Log while targeting Row 56+ on individual specimen tabs using bottom-up A100 targeting.
  • Watering.gs: Provides syncMaintenanceByDatePrompt() to validate date inputs (YYYY-MM-DD) and backfill past care records into individual ID ledgers with timestamp duplicate prevention.

3. Bloom Lifecycle & Stoplight Visual Engine Visual Indicators

Separates bloom status logging from maintenance schedule alerts to eliminate cell coordinate overlap errors.

  • Bloom Utilities.gs: Controls Cell D5 on individual ID sheets. Displays active blooms in Emerald Green (#10b981) and non-blooming states in Soft Red (#fca5a5).
  • Stoplights.gs: Restricts repotting schedule stoplights strictly to Cell D10 (Next Repot Due). Evaluates Column U (NEXT_COL) against current date: Red (Overdue), Amber (< 30 days), Green (OK).
  • Cleanup.gs: Houses forceCleanupBloomStatuses(). Evaluates A20:B33 in individual ledgers; recognizes placeholder hyphens (-) in Column B as closed cycles to reset false "In Bloom" badges.

4. Microclimate Telemetry & Maintenance Sensory Pipeline

Automates environmental sampling and Drive storage maintenance for continuous climate monitoring.

  • MicroclimateUpdater.gs: Ingests Govee 3-column logs (Milsbo, Rudsta A/B, Terrarium) and AC Infinity 5-column feeds into cabinet tracking tabs while preventing duplicate timestamps.
  • 90-Day Retention Pruning: Sweeps cabinet telemetry tabs top-down via pruneExpiredClimateLogs() and purges samples older than 90 days.
  • SystemMaintenance.gs: Safe-trashes Govee CSV backup exports older than 60 days in Google Drive via cleanupGoveeArchiveFolder().

5. Date Standardization & Export Engines Data Integrity

Maintains uniform display formatting and delivers flattened spreadsheet snapshots for external software.

  • DateUtils.gs: Executes standardizeAllOrchidInventoryDates() across Inventory, Archived Orchids, and ID sheets 1–65. Converts dates to long text strings ("MMMM d, yyyy") using forced single-quote prefixing (') to preserve Google Sheets Table structures.
  • ExportToXLSX.gs: Generates a flattened Drive copy, strips conditional formatting and dynamic formulas, unhides rows, and displays an HTML download modal for Microsoft Excel export.
  • Full Collection Harvester (v9.0.0): Extracts metadata from Sheet39 and sub-table logs across specimen sheets 1–65, staging clean arrays into external Import_Manifest, Maintenance_Log, and Orchid_Specimen_Template workbooks.

6. System Navigation & External Embeds UI / Embeds

Provides central navigation controls and external web access endpoints.

  • Sidebar.html: Docked navigation drawer featuring numeric sheet jumping (e.g., jump to sheet ID), Keiki workbook tab bridges, and one-click sheet visibility toggles.
  • webapp.gs & GreenhouseEmbed.html: Web app HTTP GET endpoint serving dark-mode status cards, live specimen counts, watering dates, research progress metrics, and an asynchronous phrase rotator.
